# Q&A

汇总 zoneu 使用中的常见问题，持续补充。

<a id="background-restrictions"></a>

## 切到其他应用后操作卡住，怎么办？

部分系统会限制或冻结后台应用，前台服务也不一定能完全避免。ColorOS 真机上已观察到：zoneu 进程与本机监听端口仍在，但后台请求超时；切回前台后恢复响应。此现象不能证明由某次系统更新引入，也不代表所有卡顿都由后台限制导致。

可以先尝试：

1. 长按 zoneu 图标 → 应用信息 → 耗电管理 / 电池用量，允许后台活动，或设为“不限制”。设置名称随系统版本变化；可能增加耗电，可自行恢复限制。
2. 回到 zoneu 查看操作状态。明确失败或超时的操作，取消后重新发起；发送、写入等操作先确认是否已经完成，避免重复执行。
3. 必要时临时分屏，保持 zoneu 与目标应用可见，比较前后台表现。这只是排查办法，不保证有效。

后台设置调整是**待验证的缓解办法**，不是通用解决方案。无需卸载或清数据；仍失败时，结合具体错误码继续排查。

<a id="local-callback-timeout"></a>

## 浏览器卡在 127.0.0.1，提示网页无法打开？

`127.0.0.1` 指手机自身，不是外部服务器。超时可能来自后台执行限制、本机监听已结束，或浏览器 / VPN 对回环地址的处理，不能直接判断为外网不通。

先按[后台限制排查](#background-restrictions)检查，再回 zoneu 取消旧授权并重新发起。旧回调可能含一次性授权码与旧端口，**不要反复刷新或收藏**；也不要仅因本机回调失败就关闭访问外网所需的代理。

反馈时提供错误码、设备与系统版本即可。截图请遮住完整回调地址，其中可能包含授权码与 state。
