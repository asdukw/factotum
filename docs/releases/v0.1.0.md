Tappet 的第一个发布：**运行在 Android 上的通用 mobile agent** —— LLM 通过工具调用直接操作手机界面
（读屏 / 点击 / 输入 / 滑动 / 启动应用）完成任务，不做单一 App 的专用适配。

源码与签名 APK 都在这个 release 里。APK 只带 **arm64-v8a**（内嵌的 Node 运行时就占了 65MB，
多一个 ABI 体积翻倍）。

## 装之前先知道这几件事

- **要你自己的 LLM API key**：装完打开 App → 左上角菜单 → 设置，选服务商（OpenAI / Anthropic /
  DeepSeek / OpenCode Go，也可以自定义），填 key。密钥存在 Android Keystore 封装里，
  不写日志、不进备份、也不会被编进包。**保存后下次启动生效**。
- **要开无障碍服务**：任务是靠无障碍执行的（控件树优先、截图兜底）。ColorOS 首次启用会弹
  「保持开启」的安全提示，不点可能被关掉。
- **首次跑任务前把目标 App 切到前台**会顺利很多；部分 App（实测微信 8.0.78）只在「触摸探索」
  开启后启动的进程里暴露控件树，这种情况任务会明确告诉你需要先强行停止那个 App 再重来。
- **只在一台设备上验证过**：一加 15T（Android 16 / ColorOS）。别的 ROM 上无障碍的启用路径可能不同。

## 验证到什么程度（如实写）

| 项 | 状态 |
|---|---|
| 会话 / 消息 / 工具调用落库（Room + SQLCipher） | ✅ 真机 |
| 原生聊天界面（流式回复、工具卡、停止/恢复） | ✅ 真机 |
| 无障碍执行层：读屏 / 截图 / 点按 / 长按 / 输入 / 按键 / 启动 / 滑动 | ✅ 真机 |
| 端到端跑通一次真实任务（OpenCode Go 这条端点） | ✅ 真机，含截图读屏 |
| OpenAI / Anthropic / DeepSeek 三个预选 | ⚠️ 配置与运行时目录对得上，但**没有用真 key 发过请求** |
| 微信那类隐藏控件树的 App | ⚠️ 有已知死结（见上），任务里会说明原因 |

## 安装

```bash
adb install -r tappet-v0.1.0-arm64-v8a.apk
```

装完按上面的「装之前先知道」配一遍。校验下载完整性可选：

```bash
sha256sum -c tappet-v0.1.0-arm64-v8a.apk.sha256
```

校验签名（确认包没被换过）—— 证书指纹应该与这里一致：

```bash
apksigner verify --print-certs tappet-v0.1.0-arm64-v8a.apk
# SHA-256: 5522b33e1010feab0ab0778c4e304c9571289879dcf0429ffc6a4dee1c9375f6
```

## 隐私

- 屏幕内容只在「给模型的工具结果」里出现，**不落日志**；日志只记计数 / 类名 / 坐标 / 错误码。
- 会话库用 SQLCipher 加密，口令由 Keystore 封装 —— 卸载即永久丢失，外部不可解。
- 不采集通知、不做聊天记录管线（相关代码已整体删除）。
- 手机上的数据发不发云端由你逐次决定：任务文本与屏幕内容是发给**你自己配置的那个端点**的。
