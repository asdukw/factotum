# v0.10.0 —— 助手回复可以朗读了

v0.9.0 之后的第一个次版本：助手说的话现在能**读出来**。

## 这一版改了什么

### 每条回复下方多了一个喇叭

「复制」旁边是 **🔊 朗读**。点它开始读，按钮变「停止」，再点停。
读的时候音乐会被暂停，读完自动恢复。

**不能直接把正文交给语音引擎**：模型写的是给人**看**的 Markdown。`**重点**` 会被念成
「星号星号重点星号星号」，代码块会被整段念完，链接会念出一串 URL，`✅` 会念成
「白色重型对勾」。所以朗读走的是与渲染**同一条** Markdown 解析，只把标记摊平成文字：
代码块与分隔线整个丢掉，换行当强制停顿（不然列表项会连成一口气）。

长回复会按句切开逐段读（一段最多 320 字）—— 切短一点，「停止」才跟手。

### 两个引擎，自己挑

设置 → **语音**：

| | 系统 TTS（默认） | 本地引擎 |
|---|---|---|
| 装完能用 | ✅ | 要先下 13MB 模型 |
| 音色 | 随 ROM，换不了 | 可选可换 |
| 联网 | 不联网 | 不联网 |
| 正文去哪 | 不出设备 | 不出设备 |

**都不走云端 TTS** —— 那会把回复正文发给另一个服务，与这个项目对正文的处理原则冲突。

本地引擎是 sherpa-onnx + 中文 VITS 模型，推理直接跑在手机上。可选两个模型，**授权写在
下载按钮旁边**：

- **超文**（13MB）—— 训练数据 CC0（公有领域），可商用。**建议先用这个。**
- 小雅（13MB）—— 数据集 BZNSYP 只授权**非商用**，自己用没问题。

### 还能调

- **自动朗读回复**：模型答完自动读，不用每次点。
- **语速**：0.5x – 2.0x。
- **音色**：系统引擎下可以挑系统里装了哪些音色。
- **试听**：读一句中文，听当前的引擎 / 语速 / 音色。

## 说明

- **APK 变大了约 13MB**（解压后约 23MB）：本地引擎的 native 库。装完不下载模型也能用
  系统 TTS。
- **本地引擎的模型下载走 GitHub**，与「版本更新」同一个来源。
- 没配本地引擎时，「朗读」用的是系统 TTS —— 设备上得有一个可用的语音引擎
  （ColorOS 自带；AOSP / Pixel 需要装一个）。
- **退到后台会停止朗读**：没有前台服务，系统随时可能冻结进程。这是刻意的，
  与「不在后台偷偷干活」同一条原则。

| 项 | 结果 |
|---|---|
| 门禁三条（格式 / detekt / Lint）+ 全部 JVM 单测 | ✅ |
| 系统 TTS：出声 / 停止 / 音频焦点 / 分段 | ✅ 一加 15T 实测 |
| 自动朗读回复 | ✅ 一加 15T 实测 |
| 本地引擎：下载模型 → 朗读 8 段读完 → 进程存活 | ✅ 一加 15T 实测 |
| tar.bz2 解包（剥目录 / 挡路径穿越） | ✅ JVM 单测真跑 |
| 本地引擎的**音质与实时性** | ⚠️ 只验了「能读完、不崩」；流畅度与音质你自己听 |

开发过程中真机踩到并修掉的一处硬崩溃（值得记一笔）：sherpa-onnx 的 JNI 按名字与签名
取回调方法，而 Kotlin 2.x 把 lambda 字面量编成 invokedynamic 之后**没有**那个专用重载 ——
`GetMethodID` 拿到 null，整个 App SIGABRT，堆栈里一个字都指不到自己的代码。
回调改成匿名对象后正常。细节见 `docs/voice.md` §4.1。

## 安装

```bash
adb install -r tappet-v0.10.0-arm64-v8a.apk
sha256sum -c tappet-v0.10.0-arm64-v8a.apk.sha256   # 可选
```

从 0.9.0 覆盖安装即可，聊天记录与已下载的模型都不受影响。
