# v0.11.0 —— 说话就能输入

v0.10.0 之后的第一个次版本。这一版把**输入**补齐了：以前只能用键盘打字，
现在可以对着手机说（本机识别，音频不出设备），控件树读不到的 App 也能把字打进去。

## 这一版改了什么

### 麦克风：说完就变成文字

聊天页输入框右侧多了一个 **🎤**。点一下开始听（有电平条和秒数），**停顿约 0.8 秒自动结束**，
识别出的文字落进输入框；想提前结束再点一下。**结果只回填、不自动发送**，你可以先改。

识别**只在本机做**，没有「系统引擎」那一档：Android 的系统识别在多数 ROM 上会把音频发给
厂商的云，而这条路上出去的是**你的声音** —— 比屏幕正文更私密。所以：

- 音频不落盘、不进日志，只在本进程内存里活到识别完；
- 模型要自己下一个（设置 → 语音 → 语音输入），**82–239MB，三个可选**：

| | 体积 | 语言 | 速度（5.6 秒中文） | 授权 |
|---|---|---|---|---|
| **Paraformer 中文（小）** | 82MB | 中文（含中英混说） | 62ms | FunASR 模型许可 1.1 |
| SenseVoice | 239MB | 中英日韩粤 | 123ms | FunASR 模型许可 1.1 |
| Whisper tiny | 103MB | 99 种 | 239ms | MIT |

**装好会自动选中**，不用再去点一次。FunASR 那两条的授权**不是** OSI 标准许可（可自由
使用 / 修改 / 分发 + 必须署名），界面把这句话原样显示在下载按钮旁边。

**端点判定用 silero VAD**（629KB 的模型打进包里，不让用户多下一样东西）。第一版是自己
算音量阈值的，真机上被一个现象否掉：点开麦克风什么都不说，它照样「听」出一句像模像样的
话落进输入框 —— 而调阈值堵不住。换成 VAD 之后，环境噪声根本不会被当成一段话，
「静音变成文字」在结构上就不可能。细节见 `docs/voice.md` §7。

### 控件树读不到的 App 也能打字了

以前 `type_text` 只有一条路：从控件树里找输入框。微信这类对无障碍隐藏控件树的 App
**能点不能打字**。现在多一条兜底 —— 无障碍服务本身带一个「文本注入通道」
（Android 13+），可以直接把文字写进当前聚焦的输入框。

**不用切换输入法**，你的键盘还是你自己那个。顺序仍然是控件树优先，通道兜底。
失败的几种情况各有各的提示：没点过输入框（先点一下它）、升级后没重新启用过无障碍、
设备在 Android 13 以下。

> **升级后请把无障碍关掉再打开一次**：这条通道写在服务的配置里，启用时才解析，
> 不重新启用就不生效。

### 工具改名（对模型可见的名字统一了）

`read_screen` → `read_ui_tree`，`capture_frame` → `capture_screenshot`。名字更贴合实际
语义（一个是读控件树、一个是取整屏截图）。对你是透明的，只在看日志时会看到新名字。

## 说明

- **APK 变大 629KB**：silero VAD 模型进了包。识别模型仍然是按需下载。
- 识别模型下载走 GitHub，与「版本更新」「朗读模型」同一个来源。
- **停顿 0.8 秒算说完**；一句话超过 10 秒会被切成两段分别识别再拼起来。
- 一次只处理一段，**不做连续听写** —— 输入框里装的是一条指令，不是聊天记录。
- **不做说话人区分、不做时间戳**：这是「把一句话变成指令」，不是转写会议。

## 验证

| 项 | 结果 |
|---|---|
| 门禁三条（格式 / detekt / Lint）+ 全部 JVM 单测 | ✅ |
| VAD 在真机上切段：4 段归档样例（中文 / 中英混说 / 河南话） | ✅ 一加 15T 实测，段数与文本均正确 |
| 切出的段交给识别器 vs 直接喂原始音频 | ✅ 逐字相同 |
| 点麦克风不说话 | ✅ 只出「没听到说话」，输入框一个字都没有 |
| 识别回归（WAV 广播） | ✅ 29 字 / 56ms |
| **麦克风收到的是不是人声** | ⚠️ 需要你对着手机说一句 —— 见下 |

**没验到的那一步**：这条路上只有「麦克风收到的音频是不是人声」无法自动验
（其它都能用 `op VAD` / `op ASR` 广播喂样例音频）。装完请点一下麦克风说句话：
应当看到电平条动、停顿后自动结束、文字出现在输入框。

开发中真机踩到并修掉的一处（值得记一笔）：VAD 的段是**等后面跟了静音才闭合**的，
所以正在说的最后一句一直悬着 —— 少了 `flush()` 就是「说完立刻按停，话没了」，
而拿一段 WAV 喂进去的表现是**切出 0 段**。新加的 `op VAD` 探针第一次跑就抓到了它。

## 安装

```bash
adb install -r tappet-v0.11.0-arm64-v8a.apk
sha256sum -c tappet-v0.11.0-arm64-v8a.apk.sha256   # 可选
```

从 0.10.0 覆盖安装即可，聊天记录、已下载的模型都不受影响。装完记得**重新启用一次无障碍**
（`adb install -r` 会摘掉它，文本注入通道也依赖这次重新启用）。
