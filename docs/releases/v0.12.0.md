# v0.12.0 —— 会说话的四个人

这一版只动了一件事：**本地朗读的音色**。原来那两条通用中文女声（超文 / 小雅）换成了
四条角色音，顺手修掉一个「不报错但声音不对」的 bug。

## 这一版改了什么

### 本地朗读换成四条角色音

设置 → 语音 → 朗读 →「本地模型」，现在是这四条（每条 120MB、22.05kHz、中/日混读）：

| 模型 | 角色 | 出处 |
|---|---|---|
| `keqing` | 刻晴 | 《原神》 |
| `eula` | 优菈 | 《原神》 |
| `theresa` | 德丽莎 | 《崩坏 3》 |
| `bronya` | 理之律者 | 《崩坏 3》 |

它们都是社区训练、由 sherpa-onnx 官方转成 ONNX 的 VITS 模型 —— 也就是**不用换引擎、
下下来就能念**的那一类。系统 TTS 仍是默认，不受影响。

### 修掉「声音是别人」的那个 bug

这批模型是「**一个游戏一份多说话人模型**」：804 个说话人装在同一个网络里，角色只是里面
的一行。而朗读引擎以前把说话人编号写死成 `0` —— **不报错、不崩溃，只是念出来的是别人**。
现在每个模型带着自己的编号（刻晴 115 / 优菈 124 / 德丽莎 193 / 理之律者 193），
`TtsModelCatalogTest` 逐个钉住。

这一类错误只有耳朵能发现，所以它值得单独写一段：**静默的错不是小事**。

### 为什么不是塔菲 / 菲比

挑音色的过程记在 `docs/voice.md` §4，这里只说结论：

- **永雏塔菲**：公开权重**全是 Bert-VITS2** 的 `.pth`，而当前引擎（sherpa-onnx）只认
  vits / matcha / kokoro / kitten / zipvoice / pocket —— 架构不同，**转换都救不了**
  （它的文本编码器吃的是 BERT 特征，不是音素 id）。自己补一套 Bert-VITS2 引擎的话：
  下载 0.7–2GB、每句 2–6 秒，工程量以周计。**判定不值得**。
- **《鸣潮》菲比**：全网**没有可用的 TTS 权重** —— HF 的 models / spaces / datasets 全量搜、
  GitHub 仓库与代码搜索、k2-fsa 的 646 个模型资产，都没有。只有一个 RVC **变声**模型
  （不是合成）和一个空仓库。

## 说明

- **这四条没有版权方授权**：音色由社区用游戏里的角色语音训练，米哈游没有授权。
  自己听没问题，**商用不行**。授权写在下载按钮旁边（和识别模型同一条规矩）。
- **旧模型不会自动删**：超文 / 小雅（各约 13MB）留在 App 私有目录里，占约 28MB，
  界面上不再出现。要清掉只能卸载重装，而那会**连聊天记录一起清** —— 不建议为这点空间折腾。
- 朗读仍不进日志、不出设备；四条模型都是**下载后本机合成**，正文不会发给任何人。

## 验证

| 项 | 结果 |
|---|---|
| 门禁三条（格式 / detekt / Lint）+ 全部 JVM 单测 | ✅ |
| 四个归档的文件布局与文件名（`keqing.onnx` / `bronya.onnx` / `eula.onnx` / `theresa.onnx`、`dict/`、三个 FST） | ✅ 逐个流式列过 |
| 用 sherpa-onnx v1.13.8 的 Windows 版真跑 theresa 与 keqing 模型 | ✅ 合成成功，RTF 0.62–0.76 |
| `sid` 确实换声音（同一句话，sid 0 / 115 / 193 输出不同） | ✅ |
| **四条音色在真机上听起来像不像本人** | ⚠️ **没验** —— 见下 |

**没验到的那一步**：说话人编号来自源合集 `zomehwh/vits-models-genshin-bh3` 的 `info.json`
（它的在线试听页用的就是同一份），但**没有真机听过**。装完请到
设置 → 语音 → 朗读 里各下一条、点试听：

- 如果听着**不是你选的那个角色**，那是 `sid` 填错了 —— 换一个编号即可（一行改动，
  见 `TtsModelCatalog`），不是引擎问题。
- 描述里写的「中/日混读」是模型本身的能力（`zh_ja_mixture_cleaners`），
  四种音色对日常中文回复都够用。

## 安装

```bash
adb install -r tappet-v0.12.0-arm64-v8a.apk
sha256sum -c tappet-v0.12.0-arm64-v8a.apk.sha256   # 可选
```

从 0.11.0 覆盖安装即可：聊天记录、已下载的识别模型都不受影响。
装完记得**重新启用一次无障碍**（`adb install -r` 会摘掉它）。
