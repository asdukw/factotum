# v0.13.0 —— 说完整句带标点

v0.12.0 之后的第一个次版本。这一版没有新功能，都在打磨两条已有链路：**语音输入**与**下载**。

## 这一版改了什么

### 边说边识别，不用等整场录完

以前是把整场会话的音频攒起来、等你说完（或者到 90 秒上限）才一次性交给识别器。
现在 VAD 每切出一段就立刻识别，**边录边出结果**，收尾只等最后那一段。

- 一句话说完就停：看不出差别（本来就只有一段）。
- 连着说很长：以前一路说到 90 秒上限，就是一次识别 90 秒音频 —— 现在等待明显变短。

代价写在明处：一句话被 10 秒上限从中间切开时，两半各自识别，边界上可能多一个断句。

### Paraformer 的整句补上标点了

Paraformer 那一档出来的是一整句**没有标点**的中文，而这句话是要交给助手的指令。
现在会**跟着它一起**装一个标点模型（61.7MB，Apache-2.0），补上逗号句号。

- **没有开关，设置页里也没有它** —— 要不要标点只取决于你选的是哪个识别模型，
  这不是一个该由你回答的问题。
- SenseVoice 与 Whisper 自带标点（前者烘在模型里，后者自己会吐逗号），**不会**下这一份。
- **已经在用 Paraformer 的**：那一条上会显示「还差 标点（中英） 61.7 MB」与一个「补下」按钮，
  点一次只拉缺的这一份，不会把 82MB 的识别模型重下一遍。删掉 Paraformer 会顺带清掉它。

装了之后，同一段音频的输出：

| | 输出 |
|---|---|
| 以前 | 对我做了介绍啊那么我想说的是呢大家如果对我的研究感兴趣呢嗯 |
| 现在 | 对我做了介绍啊，那么我想说的是呢，大家如果对我的研究感兴趣呢嗯。 |

（与 SenseVoice 自己带的标点几乎逐字相同。）

### 下载失败时说人话，并且停在那里

以前下模型失败，界面上是一行异常原文：

```
下载失败：failed to connect to github.com/20.205.243.166 (port 443)
from /172.103.8.162 (port 56054) after 30000ms
```

两个 IP 和一个毫秒数，没有一句话能照着做。现在按失败类型给出下一步：

| 情况 | 现在显示 |
|---|---|
| 连不上 / 解析不了 github.com | 打开 VPN 或换个网络再试 |
| 连上了但一直没有数据 | 网络不通或太慢，稍后再试 |
| 服务器返回 404 | 文件可能已下架，重试没用 |
| 连接中途断了 | 已下载的部分会留着，下次接着下 |

那一条的按钮直接变成**重试**，已经下载的部分留着接着下。
**不做自动重试** —— 那会让人以为「已经在下了」，而其实一次都没连上。
建连超时也从 30 秒降到 15 秒：连不上时不该让人盯着进度条干等半分钟。

### 下载中途断线不再被当成「下完了」

服务器声明了长度却提前关连接时，读到的结尾和「读完了」长得一模一样。以前会把半截文件当成
完整的一份 —— 更新包那边哈希能拦下（代价是白下几十 MB），模型那边解包失败、报的却是
「归档坏了」。现在直接报「连接中断」，半截文件留着给下次续传。

## 说明

- 识别日志里多了 `lang`（模型判定的语种）与 `event`（音频事件）两个记号，只有 SenseVoice
  会填。**都是结构不是正文**：它们不进输入框，也不进用户可见文本。
- 识别仍在**本机**做：没有云端 ASR，音频不出设备、不落盘。
- 标点模型与应用内更新走同一个下载来源（GitHub），授权是 Apache-2.0，显示在 Paraformer
  那一条的授权行里。

## 安装

```bash
adb install -r tappet-v0.13.0-arm64-v8a.apk
sha256sum -c tappet-v0.13.0-arm64-v8a.apk.sha256   # 可选
```

从 0.12.0 覆盖安装即可：聊天记录、已下载的识别模型都不受影响。
装完记得**重新启用一次无障碍**（`adb install -r` 会摘掉它）。
