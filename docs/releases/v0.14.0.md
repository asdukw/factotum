# v0.14.0 —— 语音输入不再需要选模型

这一版把语音输入的**模型选择整个拿掉**：识别只用 Paraformer，装完自动下载，
设置页里不再有这一节。行为与 v0.13.0 装上 Paraformer 时一致。

## 这一版改了什么

### 语音输入不再出现在设置页

以前「设置 → 语音」里有一节「语音输入（识别模型）」，可以在 Paraformer / SenseVoice /
Whisper tiny 之间选。现在这一节整块移除了 —— 识别模型不是一道该由用户回答的选择题：
语音输入只服务「把一句话变成给助手的指令」这一个场景，多一个选项就多一次「选错了却不知道」。

- 识别固定用 **Paraformer 中文（小）**（82MB，快、中文准），它的标点模型照旧**跟着一起装**，
  仍然没有单独开关。
- 模型在**安装后自动下载**：开机后第一次启动就开始拉，不用去设置里点。
  已经装好 Paraformer 的老用户**什么都不会重下**。
- 没下完时点麦克风会说「正在下载」，不会假装功能坏了；下载失败再点一次麦克风就会重试。

### SenseVoice 与 Whisper tiny 从目录里移除

两条都不再提供下载，设备上已经下过的那两份会在下次启动时清掉（几十到两百多 MB）。
Paraformer 与标点模型不动。

Whisper tiny 在中文上的实测明显不如 Paraformer（同一段 5.6 秒音频：输出丢字，239ms vs 62ms，
自回归解码、音频越长差得越多）；SenseVoice 多语言更好，但对「中文指令」这个场景没有必要。
留着它们只是让设置页多两个会选错的选项。

### 下载判据包含伴生件

自动下载会检查**本体与标点模型**是否都在。只装了一半（本体早在、标点是后加的）的安装
也会自动补上标点，不需要用户去任何地方点。

## 说明

- 识别仍在本机做：没有云端 ASR，音频不出设备、不落盘。
- 朗读（TTS）那一节没有变化：系统引擎 / 本地 VITS、自动朗读、语速、音色都在。
- 识别模型与朗读模型、应用内更新走同一个下载来源（GitHub）。

## 安装

```bash
adb install -r tappet-v0.14.0-arm64-v8a.apk
sha256sum -c tappet-v0.14.0-arm64-v8a.apk.sha256   # 可选
```

从 0.13.0 覆盖安装即可：聊天记录、已下载的 Paraformer 与标点模型都不受影响。
装完记得**重新启用一次无障碍**（`adb install -r` 会摘掉它）。
如果是全新安装、设备上还没有识别模型，第一次启动会自动下载约 144MB（Paraformer + 标点）。
