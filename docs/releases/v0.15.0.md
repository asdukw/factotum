# v0.15.0 —— 回复里的表格和代码块终于像样了

这一版把助手回复的 Markdown 渲染换成了 Compose 原生渲染器。以前那套手写解析只认标题、
段落、列表、引用和代码块，模型稍微写复杂一点就会「走样」；现在表格、嵌套列表、任务列表、
语法高亮都能正常显示。

## 这一版改了什么

### 表格不再是「一串带竖线的文字」

模型很喜欢用表格做对比和汇总。以前表格没有专门的渲染，用户看到的是一行行
`| 工具 | 说明 |` 和分隔线 `| --- | --- |`。现在会画成真正的表格：表头加粗、行间分隔线、
背景色、单元格内边距，列宽按内容分配。

### 列表按层级缩进，任务列表有复选框

- 嵌套列表以前会被拍平成一串同级项目，现在按缩进层级显示；
- `- [x]` / `- [ ]` 渲染成 Material 3 复选框，而不是字面的 `[x]`；
- 列表项换行后的续行仍属于同一项，不再断成新段落。

### 代码块带语法高亮

围栏代码块会根据语言标注（`kotlin`、`python`、`json` 等）着色，跟随系统深色 / 浅色主题。
代码块仍然是等宽字体、可横向滚动、可长按选中复制。

### 行内样式支持嵌套，链接有白名单

粗体里夹行内代码、删除线、斜体这些写法不再把标记符号原样画出来。链接点按前会检查 scheme：
只有 `http` / `https` / `mailto` 会交给系统打开，模型输出里的 `intent://`、`file://`、
`javascript:` 一律忽略。

### 流式回复更稳

解析在后台线程进行，高频的增量更新会自动合并；新内容解析完成前保留上一版画面，
长回复在流式过程中不再中途闪空。

## 说明

- **图片仍然不加载**：模型给出的图片 URL 不会变成设备上的网络请求，保持「模型输出只影响
  它自己的那条回复」这个边界。
- 朗读（TTS）的文本摊平逻辑没有变化：仍然会把粗体、代码块、链接念成正常句子。
- 本次升级新增了一个第三方渲染依赖（Apache-2.0），解析器为 JetBrains Markdown（GFM）。

## 安装

```bash
adb install -r tappet-v0.15.0-arm64-v8a.apk
sha256sum -c tappet-v0.15.0-arm64-v8a.apk.sha256   # 可选
```

从 0.14.0 覆盖安装即可：聊天记录、已下载的识别模型都不受影响。
装完记得**重新启用一次无障碍**（`adb install -r` 会摘掉它）。
