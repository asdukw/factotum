# v0.16.0 —— Gmail 能读也能写，危险动作先问你

这一版把 Gmail 连接器从「只读」推到「可写」，并把「危险动作先问用户」做成了手机上的确认面板。
聊天侧修了流式输出的滚动与过程卡，读屏默认只回差异。

## 这一版改了什么

### Gmail：五个只读 + 四个写

只读侧在上一版补齐了分页、会话视图、附件清单和自定义标签；这一版加上写操作：

- `mail_modify`：已读 / 未读 / 星标 / 归档 / 自定义标签；
- `mail_draft`：创建草稿，不发送；
- `mail_send`：发送邮件（不可撤销）；
- `mail_save_attachment`：把附件保存到公共 `Download/Tappet/`。

### 第一次有「审批面板」

所有写操作都会先弹确认面板（接 dsh 官方的 `dsh-user-approval` seam）：

- 面板显示工具名，以及收件人 / 主题 / 邮件 id；
- 只有点「允许一次」才执行；拒绝、关闭或没有应答者都不会执行（fail closed）；
- 同时只允许一个待审批，并行工具调用不会出现「一次点击批准两件事」；
- 思考 / 工具调用卡里的写操作同样受这条约束。

**只有一次性授权**：没有「总是允许」，也没有记住的规则。这是当前 seam 的词汇，不是遗漏。

### 附件保存到公共下载目录

`mail_save_attachment` 把附件写进系统「文件」App 能看到的 `Download/Tappet/`：

- 用 MediaStore，**不需要新权限**；
- 需要 Android 10+（更低版本公共目录写入需要存储权限，而 App 只申请 INTERNET）；
- 单附件上限 20MB；文件名会清洗路径分隔符 / 控制字符 / 超长名；
- App 不保留副本，也不写自己的私有目录。

### 流式输出不再抢你的滚动

以前生成过程中每来一个 token 就把列表滚到最后一条的**顶部**，而且不看用户手势：
长代码块会一直停在开头，用户上滑也会被拽回去。

现在：

- 跟随时把最后一条的**底部**贴到视口底部；
- 用户上滑立即暂停跟随，回到底部自动恢复；
- 右下角出现「回到底部」按钮；
- 只有换会话 / 发新消息才强制跳底，助手新消息和工具卡不会把你从历史里拽走。

### 过程卡不再无限长

- 「思考中 X 秒」实时增长，结束时变成「思考了 X 秒」；
- 多轮工具调用的展开区最高 280dp，内部自己滚动并跟随最新一步；
- 用户手动上滑后暂停跟随，滑回底部恢复；
- 停止 / 出错时会结算思考时长，不再永远停在「思考中」。

### 读屏默认只回差异

`read_ui_tree` 默认只返回与上一次读屏的差异，ref 跨读稳定；整页变化超过 50% 或换 App
自动退回全量，`full=true` 可强制全量。同屏连续操作不必每步重读。

### 语音

本地朗读模型不可用时回落到系统 TTS，不再停在不可用的本地引擎。

## 说明

- Gmail 写工具需要先在 设置 → 连接器 → Gmail 完成授权；授权面是 `gmail.modify`（读 + 写 + 发）。
- 回复 / 转发 / 批量写、多账号还没有提供。
- 设备工具插件的模型可见 schema 改为英文（0.7.0），行为不变。

## 安装

```bash
adb install -r tappet-v0.16.0-arm64-v8a.apk
sha256sum -c tappet-v0.16.0-arm64-v8a.apk.sha256   # 可选
```

从 0.15.0 覆盖安装即可：聊天记录、已下载的识别模型都不受影响。
装完记得**重新启用一次无障碍**（`adb install -r` 会摘掉它）。
