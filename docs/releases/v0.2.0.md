v0.1.0 之后的第二个发布：**流式输出**、**聊天界面按「过程块」重排**，以及**无障碍引导**。

## 这一版新增

### 流式输出

之前一次模型回复只能整段出现 —— 协议层只发「每步组装完成的整条消息」。这一版在运行时里加了
一个补丁，把进程内一直存在的 token 级增量转发出来：正文逐字上屏，界面按 50ms 合并刷新。
步进成品到达时会**只替换本步**的流式文本，多步回答的前几步不会被吃掉，也不会重复。

### 聊天界面：过程块

- 工具调用与思考过程收进**一个大的可折叠块**（收起时一行「再显示 N 步」）；里面每个工具、
  每段思考**各自可折叠**。正文永远在块外面。
- 工具不再显示 `read_screen` 这种原始名：9 个原语各有中文展示名，认不出的回落到原名。
  点开工具是底部详情：原始参数 / 调用结果 + 复制。
- 思考行显示「思考了 3.8 秒」（只在本次运行的内存里；重开 App 后显示「思考过程」）。
- 流式进行中过程块自动展开，完成后自动收起；你手动开合过之后就不再替你动。

### 无障碍引导

应用**无法自行开启**无障碍（Android 不允许）。这一版在**真的有一次设备动作因此失败**之后，
聊天页会出现提示卡（含 ColorOS 那个「保持开启」的提醒），点「去开启」直达系统无障碍设置；
设置页也有常驻的一段说明。纯聊天、模型没碰设备时**不会**打扰你。

### 依赖与工程

Kotlin 2.3.20 → 2.4.21；SQLCipher 4.17.0 → 4.19.1（已验证设备上已有的库仍能打开）；
Gradle wrapper → 9.8.1。另修了若干小问题（设置页保存后仍需重启才生效的问题依旧存在，属设计）。

## 安装

```bash
adb install -r tappet-v0.2.0-arm64-v8a.apk
sha256sum -c tappet-v0.2.0-arm64-v8a.apk.sha256   # 可选
apksigner verify --print-certs tappet-v0.2.0-arm64-v8a.apk
# SHA-256: 5522b33e1010feab0ab0778c4e304c9571289879dcf0429ffc6a4dee1c9375f6
```

装完按应用内提示做两件事：**填自己的 LLM API key**（设置页）、**开启无障碍**
（真需要时应用会提示；只能由你手动开）。
