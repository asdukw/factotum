# v0.4.0 —— 设置页与模型提供商管理

v0.3.0 之后的第四个发布：**模型不再写死在运行时里**。设置页可以管理多个提供商、
从端点拉模型列表、填写各自的 API Key；聊天页能直接切换提供商 / 模型，并按需重载
dsh 运行时 —— 不重启 App、不重启 Node 进程。

## 这一版新增

### 设置页（分组卡片）

按参考图重做：助手 / 扩展管理（占位）、模型与服务（提供商可用，其余占位）、执行层
（无障碍状态与跳转）、关于。抽屉里的入口改为齿轮图标 +「设置」。

### 提供商管理

- 列表：搜索、按显示名字母序、启用 / 禁用、可用模型数、缺 Key 标记；旧版单端点配置
  自动沿用（老用户不需要重填 key），旧 key 只属于它当时指向的那家。
- 详情三页签：**配置**（名称 / API Key / API Base Url / 是否启用 / Response API）、
  **模型**（可用模型列表、端点模型列表、手填 id）、**高级设置**（调用风格 / 推理格式 /
  验证状态 / 清密钥 / 恢复默认）。
- 密钥**每个提供商一把**，各自用 Android Keystore 封装；不进 prefs 明文、不进日志、
  不回填界面。启用 / 选中模型要求端点、模型、密钥齐全，避免把正在用的那家静默停掉。

### 模型列表（不再手写维护）

- **从端点拉取**：`GET {base}/models`（OpenAI 兼容用 Bearer，Anthropic 用
  `x-api-key` + 版本头，zen 带会话头），结果落盘，可搜索、多选加入「可用模型」。
- 端点不提供 `/models` 的，直接手填模型 id。
- 「可用模型」可增删（×）、点选为当前模型；卡片上的「N 个模型」= 可用模型数。

### 聊天页切换模型 + 按需重载

- 顶栏副标题显示「提供商 · 模型」；输入框改成两行：正文 + 工具条，左下是提供商品牌
  图标（点开切换），右下是发送 / 停止。
- 切换 sheet 对齐 RikkaHub：胶囊搜索、供应商分组（可折叠 + 模型数）、圆角模型卡
  （品牌图标 + 模型名 + 提供商，当前项高亮 +「当前」）。
- 选中后保存并**重载 dsh 运行时**：launcher 卸载整棵 cordis 根再重新 mount（实测同一
  pid 内约 0.2–1 秒），SDK 自动重新 initialize。密钥在 Node 启动时预置成
  `TAPPET_LLM_KEY_<ID>`，重载配置只写非密字段（`runtime-config.json`），**密钥不落盘**。

### 模态声明

构建期从 pi-ai 目录生成 `assets/model-modalities.json`（42 家 / 1600 个模型）；运行时
`TAPPET_LLM_MODELS` 按它声明 input。目录外的 id 一律按纯文本声明 —— 欠声明只是提前拒图，
过度声明会在请求中途被端点拒。界面不显示「可读图 / 仅文本」标签（用户要求）。

## 修复

- 手填 / 自定义模型报 `UNKNOWN_MODEL`：模型清单改为按当前选中模型动态注入。
- 自定义提供商 + Response API 的 `thinkingFormat` 与协议不匹配：只在
  `openai-completions` 时注入。
- 启用中的自定义端点被清空会让 dsh mount 失败、把 App 带崩：回落可挂载默认并清空密钥。
- 「恢复默认设置」对升级用户无效：一并清掉指向该提供商的旧版键。
- 密钥输入框使用 Password 键盘类型；`AgentConfig.toString()` 不再包含密钥；图标按钮补
  语义标签；提供商列表错误改用 Snackbar。

## 已知限制

- **切换模型会换 dsh 会话命名空间**：界面历史保留，但模型上下文从下一条消息重新开始
  （dsh SDK 只有 create、没有 resume）。sheet 里有说明。
- **改 API Key 仍然要重启 App**：key 只在 Node 启动时读入 env；模型 / 提供商切换走重载，
  不需要重启。
- 重载期间不能再次切换，任务进行中也不能切换（remount 会打断 stream）。
- 模型能力标签（对话 / 图像 / 工具 / 推理）没有做：模型 id 之外的元数据没有可靠来源，
  界面不摆猜出来的标签。

## 安装

```bash
adb install -r tappet-v0.4.0-arm64-v8a.apk
sha256sum -c tappet-v0.4.0-arm64-v8a.apk.sha256   # 可选
apksigner verify --print-certs tappet-v0.4.0-arm64-v8a.apk
```

装完按应用内提示做两件事：**填自己的 LLM API key**（设置 → 提供商）、**开启无障碍**
（真需要时应用会提示；只能由你手动开）。
