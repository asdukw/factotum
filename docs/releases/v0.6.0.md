# v0.6.0 —— dsh 能力移植第一批

v0.5.0 之后的第六个发布：**把 dsh 的能力尽可能搬到手机上**的第一批。

这一版之后，模型不再只能「看屏幕、点屏幕」——它能**联网查**、**问你一句**、**记住你的事**、
**在工作区里读写文件并检索**。全部沿用 dsh 自己的机制（seam / waterfall / 指令文件），
不是另起一套。

## 这一版新增

### 联网搜索（`web_search` / `web_fetch`）

需要屏幕上查不到的外部事实时（实时信息、新闻、不确定的说法），模型可以联网检索。

- **不接搜索 API**：Bing Web Search API 已退役、Google Custom Search JSON API 已对新客户关闭。
  走的是**模型服务商自己的**服务器端搜索 —— **零新增厂商、零新增凭据**，
  用的还是你已经配好的那把 key。
- 网页正文被标成**外部不可信数据**：其中的任何要求都不会被当成指令执行。
- 结果带来源链接，模型转述时会说清出处。

### 模型可以向你提问（`ask_user_question`）

模型需要你拍板时，屏幕底部弹出一张卡片：

- **选项、自由输入、跳过**都在；一屏一题，多题可翻页。
- **单选点了就走**；多选可以叠加自定义答案。
- **关闭卡片不等于回答** —— 模型会如实告知「没等到答案」，而不是替你猜一个。

### 长期记忆

接的是 dsh 官方的**指令文件**机制（`AGENTS.md` 那一套），落在 App 私有目录
（与会话库同级，不联网、不外传）。模型可以自己读写它：稳定的偏好与约定写进主文件，
之后每一轮都会自动带上。

### 文件读写与检索（`read` / `write` / `edit` / `glob` / `grep`）

模型可以在工作区里读写文件、按路径找文件、按内容搜。

- 检索用的是**为 Android 交叉编译的 ripgrep**（默认特性、无额外动态依赖），
  所以带的是 ripgrep 的完整语义：`.gitignore` 感知遍历、正则、并发。

### 任务清单与目标

- `todo_write`：多步任务可以先列清单，逐条推进。
- 同会话 **goal**：跨轮次保持一个目标，不必每轮重述。

### 后台任务、技能、计划模式

- **后台任务**：长命令可以后台跑，稍后取回输出。
- **技能**：从工作区文件系统发现，模型按需加载。
- **计划模式**：复杂任务可以先出计划、再执行。

### 上下文压缩

长会话不再一路撞上下文墙：旧工具结果会被压小，超长时可以压缩历史。

### 会话开始后自动收起软键盘

模型要在屏幕上操作时，键盘不再占掉小半屏，也不会作为 IME 窗口混进控件树与截图里
（那会让模型把键盘当成页面内容去点）。

## 已知限制

- **联网搜索只有 OpenCode Go 的组合实测可用**（zen 的 Anthropic 兼容端点 + `claude-haiku-5-5`）。
  **「模型接受工具」不等于「它会真的联网」** —— 有的模型收下工具、回 200、然后一次都不搜，
  所以搜索模型是单独指定的，不是当前聊天模型。
- **文件工具的路径不是沙箱**（dsh 的 fs 后端原话：`cwd` 只是相对路径的解析基准）——
  模型能读写 App 能碰到的全部路径。
- **提问没有倒计时**：dsh 原生的倒计时属于 timed 等待，这一版接的是普通等待。
- 记忆、文件与提问在**模拟器**上验的；真机上还没跑过这三条。

## 安装

```bash
adb install -r tappet-v0.6.0-arm64-v8a.apk
sha256sum -c tappet-v0.6.0-arm64-v8a.apk.sha256   # 可选
apksigner verify --print-certs tappet-v0.6.0-arm64-v8a.apk
```

装完按应用内提示做两件事：**填自己的 LLM API key**（设置 → 提供商）、**开启无障碍**
（真需要时应用会提示；只能由你手动开）。联网搜索用同一把 key，不需要额外配置。
