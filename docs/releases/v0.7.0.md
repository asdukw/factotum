# v0.7.0 —— 应用内更新

v0.6.0 之后的第七个发布：**不用再手动去浏览器里找 APK 了**。

## 这一版新增

### 应用内更新

设置 → **版本更新** → 点一下检查。发现新版本后可以在应用内下载并安装。

- **两条校验是结构性的**，不是提示文案：
  - **SHA-256** 对照 release 里发布的那份 `.sha256` —— 挡下载损坏与半截文件；
  - **签名证书比对** —— 下载到的包与**当前安装包**的签名逐字节比，对不上直接拒。
    这才是真正的防线：哈希也从同一个地方来，能换掉整个 release 的人也能换掉哈希。
- **不静默安装**：系统安装器的确认框是最后一道闸，这里只负责把验证过的 APK 递过去。
- 第一次安装会要求「允许安装未知应用」，按提示去系统设置打开一次即可。
- **不做后台轮询**：只在你点「检查更新」时联网。

## 修复

- **没开代理时，邮件工具报「未授权」**：令牌请求的网络失败以前被吞成空响应，
  于是「连不上 Google」被说成「授权失效」，用户会白跑一遍重新授权。
  现在单独归因成网络问题，并明确提示检查网络或代理；Gmail 的 REST 调用也做了同样处理。
- 设置页的「Linux 环境」按「即将推出」占位（该功能尚未开发完）。

## 验证

| 项 | 结果 |
|---|---|
| 更新检查的端到端（模拟器，Android 16） | ✅ 真实请求 GitHub Releases → 「已是最新（0.6.0）」 |
| 版本比较 / release 解析（含 apk 与 `.sha256` 必须配对） | ✅ 单测 |
| 下载 → 校验 → 安装 | ⚠️ **未在设备上验**（模拟器是 x86_64，release 包只有 arm64） |
| 门禁三条 + 单测 + 配置校验 | ✅ |

## 安装

```bash
adb install -r tappet-v0.7.0-arm64-v8a.apk
sha256sum -c tappet-v0.7.0-arm64-v8a.apk.sha256   # 可选
```

从这一版起，之后的版本可以直接在 设置 → 版本更新 里升。
