# v0.8.0 —— 定时任务与系统动作

v0.7.0 之后的第八个发布：agent 开始能**在你不看着的时候做事**，也能**动系统的钟表和日历**。

## 这一版新增

### 定时任务

设置 → 执行层 → 定时任务：每天某个时刻，让 agent 跑一句你写好的指令。

- **规则只有「每天 HH:mm」一种**。Android 没有 cron，靠得住的只有 `AlarmManager`；
  更细的粒度需要常驻进程，而那正是系统一直在杀的东西 —— 与其给一个跑不住的承诺，不如把
  边界说清楚。
- **准点需要额外授权，但不给也能用**：Android 12 起精确闹钟要单独开关
  （「闹钟和提醒」），没开就退化成 15 分钟窗口，可能晚几分钟。
- **开机后自动重排**；**错过的任务不补跑**（开机瞬间连跑十条积压任务比漏掉更糟）。
- 每条任务可以随时关掉或删除。

### 设置闹钟与新建日程

模型现在能调 `set_alarm` 与 `add_calendar_event`。

- 走**系统 intent**：时钟 / 日历 App 会带着预填内容打开，**由你点确认**。
  所以它回报的是「已打开并预填」，不是「已创建」—— 模型会如实告诉你还差一步。
- **不需要任何权限，也不需要无障碍**。直接写日历数据库要账号级的 `WRITE_CALENDAR`，
  静默设闹钟要 `SET_ALARM` —— 都不值得为一个可选功能去要。

### 更新提醒

启动时查一次新版本，发现就弹窗：**更新** 或 **跳过此版本**。

- 跳过记的是**版本号**：跳过 0.8.0 不代表以后别再提醒，0.9.0 出来照样会问。
- 查不到（没网 / 限流）就什么也不弹 —— 更新是锦上添花，不该为此打扰你。

### 悬浮球

改成**只在「任务在跑 + 你不在 Tappet 里」时出现**。停在聊天页时它挡的正是你正在看的内容，
没有意义。设置 → 执行层里可以整个关掉。

## 变更

- **无障碍成了可选功能**：不再在聊天页挂常驻提示。只有**你想要的操作真的因此失败**时才弹窗，
  并且说清是哪个操作 —— 比如「『滑动屏幕』需要开启无障碍」，而不是一句笼统的「没开」。
- 设置页的「Linux 环境」显示「即将推出」（该功能尚未开发完）。

## 验证

| 项 | 结果 |
|---|---|
| 门禁三条 + 单测 | ✅ |
| 定时任务：下一次触发时刻的边界、时间输入解析 | ✅ 单测 |
| **定时任务：到点触发 / 开机重排 / 无权限降级** | ❌ **真机未验** |
| **闹钟与日程** | ❌ **真机未验**（插件 13 个工具过真实 schema 校验） |
| 更新提醒的检查与跳过逻辑 | 单元 + 模拟器大致验过；删版本提醒的完整流程未验 |

**这一版有几条关键路径只在代码与单测层面验证过。** 想稳妥的话可以先在设备上试：建一条
2 分钟后的定时任务、让它设一个闹钟、点一次「新建日程」，确认都按预期工作。

## 安装

```bash
adb install -r tappet-v0.8.0-arm64-v8a.apk
sha256sum -c tappet-v0.8.0-arm64-v8a.apk.sha256   # 可选
```

装完按应用内提示做两件事：**填自己的 LLM API key**、**开启无障碍**（现在只有真正需要时才会提醒你）。
