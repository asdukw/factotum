# v0.9.0 —— 更新流程重做

v0.8.1 之后的第一个次版本：把**应用内更新**从「一句『正在下载并校验…』」变成一条看得见、
能取消、断了能接着下的流程。

## 这一版改了什么

### 下载有进度条了

以前点「更新」只有一句「正在下载并校验…」，116MB 的包全程没有任何反馈。现在提醒弹窗和
设置 → 版本更新 都显示进度条 + `45% · 52.1 MB / 116.5 MB`。

服务器没给总长度时（分块传输）显示**不确定进度条**，只说已经下了多少 —— 而不是编一个
卡在 0% 的假百分比。

### 可以取消，也可以后台继续

- **取消**随时可用，半截文件留着，下次接着下。
- **关掉弹窗不再中断下载**。以前下载状态挂在弹窗上，点一下弹窗外面，下载就没了 ——
  现在「后台继续」就是关掉它，进度在 设置 → 版本更新 里继续走。

### 断了能接着下（断点续传）

中断（取消 / 进程被杀 / 断网）之后重进，**从断点接着下**，不用重下整个包。
半截文件放在应用缓存里，重启手机也还在。

两条不放松的地方：

- **续传不放松校验**：哈希与签名仍是对**整包**算的，拼接出来的字节必须整份对得上。
- **服务器上那份换了就整份重来**：续传请求带 `If-Range`，同名文件内容变了时服务器会回
  完整包，而不是把两份不同的字节拼在一起。

### 缺「安装未知应用」授权时不再卡住

那是新装用户的默认状态（用 adb 装的也一样）。以前点「更新」只会回一句失败；
现在直接把你送到系统设置页，授完权回来点一次就接着下，不用重新检查版本。

## 安装

```bash
adb install -r tappet-v0.9.0-arm64-v8a.apk
sha256sum -c tappet-v0.9.0-arm64-v8a.apk.sha256   # 可选
```

从 0.8.1 覆盖安装即可，数据不受影响。

> 注意：**0.8.1 及更早版本里的更新流程还是旧的那套** —— 进度条与续传要装上 0.9.0 之后才有。
