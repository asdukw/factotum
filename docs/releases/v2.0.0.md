# v2.0.0 —— zoneu 与酒馆一体化

项目正式更名为 **zoneu**，并加入角色卡、世界书与酒馆会话。Android 包名变化属于破坏性变更，因此版本升为 **2.0.0**（versionCode 19）。

## 重要：这是全新应用，不自动迁移旧数据

- 仓库为 `asdukw/zoneu`，Android 应用身份为 `com.zoneu.app`。
- zoneu 可与旧 Factotum / Tappet 并存，旧应用和数据保持原状；数据库、会话、API key、连接器凭据及系统授权**不会自动继承**。
- 安装后需重新配置模型、连接 Gmail，并按需授权无障碍等能力。**不要为了安装 zoneu 卸载旧应用**，卸载会永久丢失其数据库密钥与本地数据。
- 数据库、prefs、Keystore、JNI、运行时配置与工具脚本同步更名。新邮件附件保存到 `Download/zoneu/`，历史下载不移动。
- 旧本机构建配置、历史发布资产与外部插件协议保留明确兼容；不改写历史 APK 的身份。

## 新增：酒馆

- **日常 / 酒馆分区**：酒馆按角色卡组织会话，可从角色详情开始对话。
- **角色卡**：PNG / JSON 导入、编辑、收藏、新建、v3 导出；世界书可单独导入导出或合入卡。
- **世界书**：关键词与次要关键词匹配、概率、常驻、位置 / 深度 / 角色、sticky / cooldown、递归层数及递归阻断。
- **预设与宏**：系统模板、后置指令、上下文预算、深度插入、会话变量与状态编辑。
- **对话操作**：候选回答切换、重写、续写、替我写；任意轮复制历史为新支线，侧栏按主线归组。
- **群聊与记忆**：2–4 张卡同场、角色独立记忆、自动与手动前情提要。
- 入口：**设置 → 娱乐 → 角色卡 / 酒馆预设**，或聊天侧栏的酒馆入口。
- Room 数据库以增量迁移升级至 v6，不使用破坏性清库。

## 修复与整合

- 保存 API key / 模型后应用运行时配置，无需重启 App；重载串行化，密钥不写入运行时配置文件。
- 运行时失败正常结束等待并显示错误；失败或停止时清掉状态占位，避免留成助手回答。
- 人格注入保留设备操作规则、当前设备时间、联网搜索及记忆边界。
- 日常设备工具、日历 / 闹钟 / 定时任务、写操作审批和内嵌 Debian 保持可用。

## 能力与隐私边界

- 酒馆直连目前仅支持 OpenAI 兼容提供商；回落到 dsh 时，深度插入、续写 / 替我写和自动提要等直连能力受限。
- 支线是复制历史的新会话，不是同一会话内的消息树。
- 外部卡的 `system_prompt`、`post_history_instructions`、`mes_example` 不导入；请只导入可信卡。
- 酒馆请求会向所选模型提供商发送人设、命中的世界书、角色记忆、历史与提要；自动提要会额外调用模型。
- 卡、角色记忆及偏好保存在应用私有目录，并非全部由 SQLCipher 加密；不应当作密钥保险箱。消息与会话仍在 SQLCipher 数据库中。详见 `docs/roleplay.md`。

## 验证状态

- 合并源码已通过 CI、Assemble、CodeQL；本地 508 项 JVM 测试、androidTest 编译、Spotless、detekt、Android Lint 和 debug APK 构建通过。
- 运行时 profile 已用真实解析器校验；debug APK 已验签并检查应用身份、native / proot / persona 载荷和内层运行时 ZIP；源码、历史与 APK 密钥扫描通过。
- **zoneu 合并包尚未完成真机验收**：角色卡导入、数据库升级、嵌入 Node 启动与真实设备任务仍需设备验证。CI 通过不代表这些路径已实测。
- 签名 release APK 由本次发布工作流另行构建、验签并检查载荷与包内密钥，不将 debug APK 作为发布资产。
